## 发布操作：必须把本地图片变成公众号图片

**本地预览能显示图片，不代表复制后公众号能显示。复制按钮只复制文字、样式及图片引用，不上传图片。不要直接发布粘贴结果。**

1. 打开 `preview.html` 审稿，替换末尾姓名、简介（建议修改原稿后重新装配，或在公众号里替换）。点击“复制到公众号”，在公众号编辑器粘贴。复制失败时只选中文章正文复制，避免带入预览工具栏。
2. 在公众号正文中找到四个图位，从本地选择对应图片上传／插入。若粘贴后是空白图、破图或临时可见图，都删除旧图节点，使用公众号的图片上传功能重新插入，不要留下两个副本。
3. 图位顺序如下：

| 图位 | 上传文件 | 所在位置 |
| --- | --- | --- |
| １ | images/01-home.png | 开场介绍之后、第一章之前 |
| ２ | images/02-notebooks.png | “轻量富文本”说明之后 |
| ３ | images/03-code.png | 代码块说明之后 |
| ４ | images/04-mobile.png | 第三章的链接与扫码说明之后 |

4. 保留每张图下方已有图注；图片用原图上传，不模糊，不把整篇长截图当正文。
5. 在封面设置中上传 `cover-wide.png`，按后台预览调整裁剪；方图可使用 `cover-square.png`。填入标题、摘要和作者。
6. 在公众号中保存后刷新／重新进入编辑器，确认四张图仍可加载。发手机预览，逐张点开检查清晰度，确认正文、图注、署名和体验地址 `https://2space.cn` 完整，检查链接在该公众号的实际可点击性。普通正文外链是否可点击由公众号权限与编辑器决定；不承诺自动成为可点击按钮。必要时提示读者复制地址到浏览器。
7. 手机预览通过后再由用户决定正式发布。

另一种流程是先获得已授权、可公开且可访问的 HTTPS 图片地址，再替换正文 HTML 的四个 img src 并重建预览。**本次没有这些公网素材地址**，不要把 localhost、相对路径或编造的图床地址写成正式素材链接。本次无须为交付而新开图床。
