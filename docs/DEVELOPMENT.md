# 2Space 1.0 开发规范

## 目标

品牌2Space；口号“这边复制，那边就有。”。工具优先，轻量富文本粘贴保格式、代码保缩进、跨端同步、私密可控。
1.0支持最多6份文本笔记、自动保存、代码高亮、富文本/纯文本复制、TXT下载、二维码分享、真正只读与撤销、临时保留、加密正文、本地草稿恢复。图片二期，不提供任意文件、账户、AI、CRDT。
匿名空间无名称抢占问题：随机ID定位，能力凭证授权；名称是密文中的笔记标题。

## 架构

单仓npm workspaces：apps/web(React/Vite/Tiptap)、apps/server(Fastify/SQLite)、packages/shared(纯类型与常量)。浏览器AES-GCM加密正文，API只存密文。单实例SQLite+SSE，Docker volume持久化。生产扩容不是1.0目标。
Tiptap按需加载；只安装所需节点，不引入完整文档套件。保留标题/段落/加粗/斜体/下划线/列表/链接/引用/简单表格/代码。粘贴去脚本、样式、图片、跟踪和危险URL。

## 模块边界

前端 owns apps/web；后端 owns apps/server；交付任务 owns Dockerfile/compose/scripts和运行文档；架构负责人 owns shared、根配置、依赖锁、规范和集成。任何任务不得自行更改共享接口。
内部任务并行同一工作区、目录隔离，不同时运行npm install、不交叉git commit、不回滚他人文件。负责人统一装依赖、运行集成、提交。长期开发改为独立分支/worktree+PR，每任务小提交，主分支只接已验收工作。

## 验收与门禁

TypeScript strict；依赖精确锁在package-lock。单元/集成围绕权限、输入、加密、冲突、到期与清理；本地浏览器验证创建、富文本、双页同步、只读、撤销、手机布局。Docker构建运行后验证health与持久化。未验证项目必须明确列出。
服务仅绑定127.0.0.1:3210；开发前端5173同样loopback。禁止公网发布、修改DNS或操作其他容器。
日志不含正文、令牌、密码或完整URL；referrer-policy no-referrer、CSP、安全响应头。浏览器片段持有密钥，JS供应链/终端被攻破仍有风险。

## 视觉方向

工作台优先，双空间符号作为品牌点。色板：纸白#FFFFFF、浅雾#F3F6FA、墨蓝#18253B、主蓝#3159DB、边线#DEE5F0、成功绿#28755D。中文PingFang SC/系统无衬线，代码SFMono/Consolas。左侧窄笔记列表，右侧安静编辑面；移动端折叠列表。选区工具或精简工具条，避免Word菜单与宣传卡片墙。真实安全能力用简明状态和详情说明，不把加密参数摆在主流程。
评审：不采用巨幅营销首屏和通用卡片墙，打开直接看到编辑任务；两格符号是唯一主要品牌装饰。字体不拉远程资源。
