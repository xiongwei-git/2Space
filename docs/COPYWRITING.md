# 用户界面文案铁律

用户明确纠正（2026-10-29），适用于本项目及后续交付偏好。

1. 用户界面只解释用户能做什么、发生什么、下一步怎么做。不出现本地开发版本、HTTPS部署、容器、数据库等维护说明；维护信息只进开发/运维资料。不机械塞入无关广告或统计宣告。
2. 权限直接说明：可编辑链接允许查看与修改；仅查看页面不能编辑。public空间知道名称即可另开可编辑页面，不能把页面模式宣传成权限隔离；private旧空间按真实权限说明。
3. 状态说结果：“已保存”“保存中”“保存失败，请重试”。不显示加密/鉴权/封装/复用等实现过程，不把原始服务端诊断直接显示给用户。
4. 动作说结果：“复制内容”“仅复制文字”“另存为新笔记”“关闭分享”。同一操作的按钮、提示和说明保持一致。
5. 风险不能藏：删除无法找回；链接/密码丢失的结果；关闭分享无法收回已复制内容；公开空间的访问范围。用明确短句解释，不用“私密可控”代替事实。
6. 参考站复刻也必须遵守本规则；保留功能与布局，不复刻错误承诺、他人身份或技术化维护提示。产品版本号可保留为已登记的辅助信息。

## 对照例子

| 不使用                                    | 使用                                 |
| ----------------------------------------- | ------------------------------------ |
| 私密空间 · 管理链接可编辑                 | 拿到此链接的人也能修改所有笔记       |
| 已加密保存                                | 已保存                               |
| 本机副本 / 远端版本                       | 另存为新笔记 / 使用已保存的内容      |
| 请求格式无效 / 管理凭证无效               | 检查输入或重新复制完整链接           |
| 当前为本地开发版本，公网部署必须使用HTTPS | 从产品界面删除，维护要求写入运维资料 |

## 门禁

`npm run copy:check`检查受控界面字符串（含无障碍名称），接入`design:check`和CI。用户笔记与代码内容不扫描、不改写。此检查只能挡住已知禁用表达，不能代替逐页人工阅读；每次交付仍检查正常、空白、分享、密码、错误、离线、冲突和到期状态。
