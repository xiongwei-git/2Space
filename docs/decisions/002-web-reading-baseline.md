# ADR-002: 以语义Tokens和浏览器验收落实Web阅读基线

## 状态与日期

Accepted；2026-10-29用户批准。

## 背景

原页面有9–11px界面信息，首页大标题与说明失衡；功能测试和一般截图检查无法阻止复发。用户要求跨项目统一阅读底线，保留各项目的视觉风格。

## 决定

共享规范承载web-reading-v1；本机全局AGENTS触发读取，frontend-design原文不变。2Space先试点：正文16px、控件和次要正文14px，12px仅元信息白名单，rem支持用户字体设置。项目文档、Tokens和检查随仓库版本演进；CI不依赖共享仓库的本机路径。

采用精确锁定的Playwright和axe开发依赖，在随机本地端口、临时SQLite数据库上检查实际DOM与计算样式，并输出合成截图。静态门禁防止绕过Token；浏览器扫描防止继承和断点覆盖。人工看图与原生缩放补足自动工具不能判断的内容。

## 替代方案与代价

只修改Skill缺少可验证门禁，也会维护本地分叉；只扫CSS不能证明最终样式；只做像素截图无法判断文字角色和业务重要性。未采用Ant Design组件库，避免无关迁移。

新增浏览器开发依赖和CI下载成本，截图审查仍需人或能看图的Agent。截图只在本地输出/CI临时产物，不作为跨平台像素基准；真实手机、Safari/Firefox及全站WCAG合规不由本试点自动证明。不改服务端契约、加密或数据结构，不扩展到其他项目或公网。
