# ADR-005：2Space整体布局与内容改版

状态：用户授权实施，2026-10-29；基线ccd9089。

用户在首页首次点击导航修复后，允许重新设计整体布局并调整全部文案。这一授权取代先前必须照搬参考站风格的布局要求；功能、旧数据和权限规则继续保持。

## 方向

“两个空间，一条内容”：保留原双格logo、主蓝#3159DB及slogan，以名称入口和真实内容示例解释跨设备使用。首页采用左右分栏，文字说明、实际格式示例与访问规则各占适合的空间，减少重复口号、同款卡片和重复创建入口。不继续展示未经实时核实的竞品功能比较表。

工作区采用1180px内的主编辑画布及280px工具栏。顶部只保留内容复制、下载和分享；密码、保留时间、访问说明放在旁栏，二维码与信息保留。窄屏自然重排到编辑区下方，不压低字号、不截断正文。弹窗统一任务标题、说明、输入、结果按钮的层级。顶部导航使用原生锚点，预留固定头部高度。

## 阅读与文案

使用frontend-design和web-reading-v1，沿用DEVELOPMENT中的Type Scale：正文/代码16px，控件/短说明14px，明确元信息12px，区域标题20px，页面/弹窗24px，首页32–48px。字体为本机中文无衬线与代码等宽回退；不引入远程字体、图片或新增依赖。

文案围绕动作、访问范围、结果与恢复办法。保留“知道名称可查看和修改、密码可选”的明示；新空间仅查看链接是页面模式，旧private链接的真正权限保持。不使用绝对安全、端到端私密等不符合当前新空间实现的承诺。密码、删除、到期与分享失效后果不藏进小字。

## 实施边界与验收

不改API、加密/存储格式、自动保存、同步、锁定、旧链接和富文本清理；不写回已有内容，不做图片、文件、账号或代码执行功能。首页样式单独维护，静态字阶检查覆盖所有CSS。

门禁包括typecheck、原单元/集成、完整浏览器计算样式/对比度/axe、1280/390/320重排、文字200%与间距、正常/错误/离线/冲突/权限/弹窗。浏览器中的内容必须是合成数据。实际查看截图后才能报告视觉结果，原生缩放与实体设备仍需单独列明。仅更新本地Docker，更新前保留在线数据库备份和旧镜像，更新后核对既有记录摘要，不清卷、不部署公网。
