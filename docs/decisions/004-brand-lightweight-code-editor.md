# ADR-004：恢复双格品牌与精简代码编辑器

状态：已批准，2026-10-29。基线提交23557c3。

用户要求在参考对齐版上恢复我们原来的logo与slogan，并让文本编辑器对程序员友好、减少复杂工具，明确不需要表格。

## 决定

- 复用f8962f5的双格标记和“这边复制，那边就有。”。恢复自己的品牌文案，不回退已完成的名称直达、二维码、密码、期限与同步流程，也不恢复旧版不适用于public的隐私承诺。
- 沿用现有Tiptap和lowlight，代码入口直接可见，支持语言高亮、行号、原文复制、Tab/Shift+Tab缩进。正文与代码默认16px、控件14px，遵守web-reading-v1；手机重排，代码允许局部水平滚动。
- 删除表格创建与表格依赖，新表格粘贴转为行列文字；既有表格必须保留全部单元格内容与行列关系。浏览器载入转换不得触发自动保存，不修改已有数据库、密文或版本。真实编辑后才保存新的简化文档。
- 保留常用富文本粘贴的语义格式，收紧可见工具数量；不引入完整IDE、代码执行、格式化服务或远程字体。

## 取舍

不引入Monaco/CodeMirror整套IDE组件，避免双编辑器模型与额外包体；不只隐藏表格按钮却继续把表格作为新增能力。表格转换以文本内容完整为先，不保留表格布局。public/private、密码、期限、分享与服务端API不变。

## 验收

品牌在首页、工作台与favicon一致；代码高亮、行号、缩进、复制、只读、富文本粘贴及表格文字保留使用合成数据验证。既有权限/保存/锁定/离线/冲突/旧链接门禁继续运行。仅本地Docker更新前备份并核对旧记录；不部署公网。
